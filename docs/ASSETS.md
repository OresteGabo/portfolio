# Portfolio artwork

- `kigali_hero.jpg`: user-supplied photograph, original filename `pexels-faustin-nkurunziza-2151028521-31466702.jpg` (Faustin Nkurunziza, Pexels). Resized and compressed for the app. Visual darkening and gradients are rendered in Compose, leaving the photograph itself unchanged apart from sizing/compression.
- `logo_bnr.png`, `logo_bk.png`, `logo_im.png`, `logo_bralirwa.png`, `logo_cimerwa.png`, `logo_kcb.png`: supplied by the user in the `Logo 3` folder; resized/converted for shared Android/iOS resources. Company marks are shown as images without tinting. Unsupported symbols use a text fallback rather than an invented logo.
- The decorative hero pattern is drawn in shared Compose Canvas, inspired by the geometric diamond lines of Rwandan imigongo. It is decorative and excluded from accessibility content.
- The supplied AI dashboard is a layout reference only; its illustrative financial figures, performance graph, notification controls and profile badge are not app data.

- `logo_mtn.png` and `logo_equity.png`: supplied separately by the user as `New-mtn-logo.jpg` and `equity-bank-logo.png`. Optimized for shared app resources and mapped to MTNR/MTN and EQTY/Equity, respectively.
